# تطبيق "افتح لي"

قل أو اكتب اسم التطبيق فيُفتح. مثال: "افتحلي الواتس" أو "شغللي يوتوب" أو "open camera". أندرويد فقط (حزمة `com.abdo.iftahli`).

## المزايا
- **قراءة التطبيقات المثبتة فعليًا** على الجوال، مع أسماء دارجة جاهزة (واتساب = الواتس، فيسبوك = الفيس...) في `apps.js`.
- **أوامر مخصصة**: من تبويب "أوامري" تربط أي جملة بتطبيق، ولها الأولوية على الفهم التلقائي. تدعم النسخ الاحتياطي (تصدير/استيراد).
- **الصوت داخل التطبيق** عبر خدمة Google (عربي، يحتاج إنترنت). يجرّب تلقائيًا `ar-EG` ثم `ar-SA` ثم `ar` لتفادي خطأ "اللغة غير متاحة".
- **الدائرة العائمة 🎤** فوق أي تطبيق: اضغطها وقل الأمر، ضغطة طويلة تعرض الأكثر استخدامًا، واسحبها إلى ✕ لإغلاقها. تعيش كخدمة أمامية وتعود بعد إقلاع الجهاز (على realme فعّل Autostart).
- **البصمة الصوتية (أوفلاين)**: اضغط مطولًا على تطبيق وسجّل اسمه 3 مرات، فيُفتح بلا إنترنت. من "ضبط البصمة" تضبط العتبة وتختبرها.
- **أوامر الجهاز**: الكشاف، "آخر تطبيق"، وفتح إعدادات الواي فاي والبلوتوث والطيران (أندرويد 10+ يمنع تغييرها برمجيًا).
- الأكثر استخدامًا وآخر ما فتحته يظهران في الشاشة وفي الدائرة.

## المعمارية (طبقات)
1. **الالتقاط**: Google Speech أو البصمة الصوتية (كوتلن) ← نص/بدائل.
2. **القرار** `resolver.js`: يحوّل البدائل إلى قرار واحد (جهاز / تطبيق مؤكد / غامض / تأكيد / غير مثبت / غير مفهوم). مشترك بين الشاشة والدائرة.
3. **الفهم** `matcher.js` + `deviceCommands.js` + `commandStore.js`: JS صِرف قابل للاختبار بـ node.
4. **التنفيذ**: الشاشة تعرض رسالة، والدائرة تعرض Toast.
5. **شبكة أمان أصلية** `NativeMatcher.kt`: لو لم تكن واجهة JS حية وقت نطق الأمر، يفتح التطبيق بمطابقة تامة (أوامرك المخصصة، اسم التطبيق، أشهر الأسماء العربية).

## حدود لازم تعرفها
- مش ذكاء اصطناعي: قواعد لتنظيف الجملة ومقارنتها بأسماء التطبيقات، مناسبة لهدف واحد زي ده.
- لو التطبيق اسمه إنجليزي على الجوال وإنت بتقول اسمه بالعربي (مثل "فودافون" ← Vodafone Ana)، المشهور مجهّز، وغيره تربطه بأمر مخصص مرة واحدة.
- لو أمرك ينطبق على أكثر من تطبيق (جوجل: Maps وPhotos...) يسألك تقصد أنهي واحد.
- **ما يشتغلش على Expo Go**: فيه جزء أندرويد أصلي، فلازم تثبّت ملف الـ APK الكامل.
- بعض الجوالات توقف الخدمات الخلفية: استثنِ التطبيق من توفير البطارية لو الدائرة اختفت.

## تطلع APK
1. ارفع كل الملفات على GitHub (تأكد من رفع `modules` وعدم رفع `node_modules`).
2. اربط المستودع بمشروع Expo **الصحيح** (`ifta7-li-v2`) — رقم المشروع في `app.json` ← `extra.eas.projectId` لازم يطابقه.
3. شغّل Build لأندرويد ببروفايل `preview` أو `production` (الاتنين يطلعوا APK).

أو من الكمبيوتر:
```
npm install
npx eas-cli build --platform android --profile preview
```

## الاختبارات
`npm test` يشغّل اختبارات الفهم والمخزن وأوامر الجهاز والمُقرِّر (كلها JS صِرف).

## الملفات
- `App.js`: الشاشة (تبويب التطبيقات + تبويب أوامري).
- `resolver.js`: طبقة القرار. `matcher.js`: فهم الجملة. `deviceCommands.js`: أوامر الجهاز. `commandStore.js`: الأوامر المخصصة والاستخدام.
- `apps.js` الأسماء الدارجة، `synonyms.js` المرادفات، `appList.js` دمج المثبت مع المعروف.
- `modules/installed-apps/`: الجزء الأصلي: `InstalledAppsModule.kt` (الجسر) و`SpeechEngine.kt` (Google) و`BubbleService.kt` (الدائرة) و`VoiceEngine/MicRecorder/Mfcc/Dtw/VoiceStore.kt` (البصمة) و`NativeMatcher.kt` (شبكة الأمان) و`Prefs.kt` و`BootReceiver.kt`.
- `test-*.js`: الاختبارات.
