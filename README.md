# المساعد الشخصي جروك — افتح لي

تطبيق أندرويد صوتي لفتح التطبيقات وأوامر الجهاز، مع أدوات مساعدة وتصميم محدّث.

## المزايا
- فتح التطبيقات بالصوت أو الكتابة (عربي / إنجليزي)
- دائرة عائمة + بصمة صوتية أوفلاين
- أوامر جهاز (كشاف، إعدادات...)
- تبويب أدوات (خصم، تحويل وحدات، عمر...)
- Wake Word Matcher + حالات جلسة صوتية
- سجل محادثة محدود + سياسة أفعال حساسة

## التصميم
- أيقونة وSplash جديدان
- ثيم داكن/فاتح بألوان تركواز
- معاينة التصميم: افتح `design-preview.html` في المتصفح

## البناء
```bash
npm install
npx eas-cli build --platform android --profile preview
```
المشروع يحتاج build أصلي (مش Expo Go) بسبب وحدات Kotlin.

## الاختبارات
```bash
npm test
```
